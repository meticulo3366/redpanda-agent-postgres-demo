Why together

Memory is data. Store it in a database, stream its changes, govern who touches it.

Store

PostgreSQL

  • Where the operational data already lives: system of record and agent memory in one transactional database
  • JSONB and full-text search built in, pgvector optional for semantic recall
  • Logical replication is the change feed; Redpanda Connect postgres_cdc turns it into topic events
  • Managed high availability: Multi-AZ failover, read replicas, point-in-time recovery

Stream

Redpanda Cloud

  • The memory change stream is the audit trail
  • Redpanda Connect materialises memory_audit from it
  • A third pipeline turns account events into memories

Govern

Agentic Data Plane

  • Identity and Cedar policy on every call
  • Guardrail and data policy act before the model sees anything
  • MCP blocklist and database grants with no DELETE
  • Transcripts and an audit log

What we learned

  • Secrets used by managed MCP servers need the AI Gateway scope as well as the MCP server scope.
  • In the current gateway build a Bedrock guardrail fires only on invoke, not on the agent's converse-stream path (observed 15 Oct 2026, may change), so the agent runs on the Anthropic provider, where the gateway evaluates the guardrail on every input and output.
